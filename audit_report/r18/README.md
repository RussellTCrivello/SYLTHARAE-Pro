# Round 18 — every file with an oracle now verifies complete

Everything in `REPORT.md` is generated from `final/records.jsonl` (the post-fix
run) by `tools/audit/build_audit_report.py`, with the prose register in
`tools/audit/registers/r18.json`. `DIFF.md` is generated by
`tools/audit/diff_runs.py` and compares this round against **round 17's final
run**, which is the regression gate. `archive/records.jsonl.gz` is this round's
own pre-fix baseline (taken after the first four fixes, before the last two), so
the round has its own before/after as well as the cross-round one.

## Reproducing

```bash
# one command: audit the corpus, then print the report command
PYTHON=/tmp/rv/bin/python tools/audit/run_audit.sh audit_report/r18/archive

# the report itself
/tmp/rv/bin/python tools/audit/build_audit_report.py \
    --records audit_report/r18/final/records.jsonl \
    --register tools/audit/registers/r18.json \
    --out audit_report/r18

# the regression gate
/tmp/rv/bin/python tools/audit/diff_runs.py \
    --baseline audit_report/r17/final/records.jsonl.gz \
    --final    audit_report/r18/final/records.jsonl \
    --out      audit_report/r18
```

Limits, recorded in every record: **180 s** wall clock per file, **2048 MiB**
address space per child (`--timeout`, `--memory-mb`).
